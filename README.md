# BDIKAT-MOZAR

אפליקציה מקומית (קובץ HTML יחיד) לבדיקת דגמי רכב בנייד.

## יכולות

- הזנת שדות קבועים ידנית:
  - שם הדגם
  - מספר שלדה
  - רמת גימור
  - מספר דלתות
- העלאת מפרט PDF והמרה ראשונית ל-Markdown.
- בניית צ'קליסט דינמי מתוך Markdown (אבזור/בטיחות + סעיפים).
- העלאת תמונות של הדגם הנבדק.
- יצירת דוח אחד שמכיל:
  - פרטי הדגם
  - הצ'קליסט והסטטוסים
  - התמונות
- ייצוא הדוח ל-PDF או ל-PNG.
- התחלת "דוח חדש" בניקוי מלא של הנתונים.

## הרצה מקומית

1. פתחו את `index.html` בדפדפן בטלפון/מחשב.
2. לחלופין, הפעילו שרת מקומי:

```bash
python3 -m http.server 8080
```

ואז גשו ל:

- מחשב: `http://localhost:8080`
- טלפון באותה רשת: `http://<IP-של-המחשב>:8080`

## מבנה Markdown מומלץ למפרט

```md
## אבזור
- מולטימדיה 12"
- חיישני חניה קדמיים

## בטיחות
- בלימה אוטונומית
- תיקון סטייה מנתיב
```

> ניתן לערוך את ה-Markdown ידנית לפני בניית הצ'קליסט, לשיפור דיוק.
